# X 计划助手（Chrome 插件）

读取 web.cafe「社媒运营 X 计划」群里**《群友优质 Post 列表（互关锚点·持续更新）》**沉淀帖，
每日从未关注的群友中随机推荐若干位，本地管理关注进度。

> 一键关注 = 仅在本地标记「已关注」，不会自动操作你的 X 账号，安全不违规。
> 你通过每行的「直达推文」按钮自行前往 X 互动关注。

## 功能

1. **自动读取并保存列表**：打开 web.cafe 沉淀帖页面时自动抓取（昵称 / 账号 / 推文链接 / 一句话说明）；也可在设置里点「立即同步」。
2. **全部账号列表**：展示所有账号与备注，支持搜索、按昵称/账号/备注过滤、一键「仅看未关注」。
3. **每日关注数设置**：自定义每天推荐几人。
4. **今日待关注（单独页面）**：每天从未关注的人里随机挑选；可「重新随机」，结果必为未关注者。
5. **一键关注**：把当前批次标记为已关注，状态同步到全部列表（绿色✓图标）；标记后保留在今日列表，需手动「重新随机」才换新一批。
6. **直达推文**：推荐列表与全部列表每行都有按钮，点击在新标签打开对方优质推文。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `D:\xPlanHelper`。
4. 工具栏出现 X 计划助手图标，点开弹窗 →「打开面板」。

## 使用

- **首次安装**已内置 30 条种子数据，开箱即用。
- **今日待关注**：顶部看进度 →「一键关注当前批次」标记 → 点各行「直达推文」去 X 关注。
- 想换一批：点「重新随机」（仍只从未关注者中抽）。
- **数据更新**：访问 web.cafe 帖子页会自动同步；或在「设置」→「立即同步」（会打开帖子页，抓完自动关闭）。
- 跨天打开面板会自动重抽今日推荐。

## 文件结构

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单 |
| `background.js` | service worker：存储、合并去重、消息中枢、标签管理 |
| `content.js` | web.cafe 帖子页表格抓取器（MutationObserver 轮询 + 手动同步后自动关页） |
| `panel.html / panel.js` | 全页面三视图：今日待关注 / 全部账号 / 设置 |
| `popup.html / popup.js` | 工具栏弹窗：今日进度 + 打开面板 |
| `styles.css` | 设计令牌 + 组件样式（Inter / teal / SVG 图标 / 无障碍） |
| `icons-svg.js` | 内联 SVG 图标（Lucide 风格） |
| `data/seed.json` | 首次安装种子数据（30 条） |
| `icons/` | 16/48/128 插件图标 PNG |
| `tools/make-icons.js` | 图标生成脚本（`node tools/make-icons.js`） |

## 数据与隐私

- 所有数据保存在本地 `chrome.storage.local`，不上传任何服务器。
- 插件只读取 web.cafe 帖子页内容，不读取也不操作你的 X 账号。

## 同步逻辑

- 以 X 账号 `handle` 为主键合并；同步时已关注的标记不会丢失。
- 抓取定位含「博主 / 优质 Post / 一句话说明」签名的表格，避免误抓。
- web.cafe 是 Next.js SPA，content script 用轮询等待表格渲染后提取。
